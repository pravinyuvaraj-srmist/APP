# Tutorial 10 — Functional Programming and Logic Programming

Solutions for all seven questions in the uploaded Tutorial-10 sheet.

## Requirements
- Python 3.9+
- SWI-Prolog for Questions 5–7

## Run
Run Python files with `python3 q1_student_marks.py` (replace the filename as needed).
Run Prolog files with `swipl -s q5_course_eligibility.pl` (replace the filename as needed), then query the predicates shown in each file's comments.

Each question is independent and includes sample data/output-oriented printing.
