# Tutorial 11 — Networking, SymPy, DFA and NFA

Solutions for all six questions in the uploaded Tutorial-11 sheet.

## Requirements
- Python 3.9+
- SymPy: `python3 -m pip install sympy`
- automata-lib: `python3 -m pip install automata-lib`

## Run
Start each server in one terminal, then run its matching client in another terminal:
- Q1: `python3 q1_tcp_server.py`, then `python3 q1_tcp_client.py`
- Q2: `python3 q2_udp_server.py`, then `python3 q2_udp_client.py`

Run Q3–Q6 directly with Python. The networking examples use localhost and demonstration data; change the host to a reachable server address when testing across machines.
